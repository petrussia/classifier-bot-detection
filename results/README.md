# Результаты

`validation_summary.csv` и `development_models.csv` — сохранённые таблицы из первоначального `antibot_solution.zip`, без пересчёта и редактирования чисел. Вторая таблица относится к исследовательскому сравнению; основное временное сравнение находится в первой.

`refactor_checks.json` и `tests.txt` — проверки новой версии. Для полного повторного запуска используйте `solution.ipynb` или `python solution.py --mode all`: новые предсказания и метрики записываются в `artifacts/`, исторические таблицы не перезаписываются.
