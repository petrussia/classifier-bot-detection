# Детекция ботов по событиям

Для каждой `cookie_id` модель выдаёт score от 0 до 1. Чем он выше, тем вероятнее автоматизированный трафик. Метрика задания — максимальный Precision среди порогов с Recall ≥ 70%.

Готовый ответ — [`submission.csv`](submission.csv). Локальная оценка на отложенных датах: **0.807143**. Это не оценка скрытого теста.

## Запуск

Проверенное окружение: **Python 3.13.5**, версии библиотек — в `requirements.txt`. Для воспроизведения эталона используйте Python 3.13; работа на 3.14 здесь не проверялась.

Распакуйте выданные данные рядом с кодом:

```text
data/
├── train.csv
├── test.csv
└── events.csv.gz
```

```bash
python -m pip install -r requirements.txt
python tests.py
python solution.py --mode all
```

Последняя команда проверит модель на holdout, затем обучит её на всём train. Новый ответ появится в `artifacts/submission.csv`; исходный файл в корне не перезаписывается. Вместо скрипта можно последовательно выполнить `solution.ipynb` в Jupyter или VS Code.

Отдельные режимы: `--mode train` — обучение без проверки; `--mode validate` — только holdout; `--mode predict` — предсказания из `artifacts/models` после обучения. Пути задаются через `--data-dir` и `--output-dir`.

## Решение

События отбираются по `window_start_ts <= event_ts < window_end_ts`, затем удаляются полные дубликаты. Разные действия с одинаковым временем остаются. Признаки считаются отдельно для каждой куки.

`features.py` содержит базовые группы: частоты действий, разнообразие объявлений и запросов, активность, интервалы, сессии, переходы, выдачу и курсор. `features_extra.py` добавляет статистики коротких пауз, скользящие окна, переходы всех типов, навигацию и геометрию курсора. Каждая группа вынесена в отдельную функцию `_add_*`.

Сырые идентификаторы, абсолютные даты и полная строка User-Agent в модель не передаются. Категории и константные столбцы определяются по обучающей части. После отбора CatBoost использует 355 признаков, LightGBM — 665.

```text
score = 0.5 × mean(CatBoost: seeds 42, 1337, 2026)
      + 0.5 × LightGBM: seed 42
```

## Проверка качества

Разбиение по времени соответствует расположению test после train. Первые два периода использовались для выбора решения, последний — для отложенной проверки.

| Обучение, апрель 2026 | Проверка | Baseline RF | Ансамбль |
|---|---|---:|---:|
| 6–10 | 11–13 | 0.093220 | 0.838323 |
| 6–13 | 14–16 | 0.099639 | 0.816568 |
| 6–16 | 17–19 | 0.095718 | 0.807143 |

Здесь везде Precision при Recall ≥ 70%. Baseline — Random Forest на числе событий и уникальных объявлений. Результаты отдельных моделей сохранены в [`results/validation_summary.csv`](results/validation_summary.csv); сравнение исследовательских вариантов — в [`results/development_models.csv`](results/development_models.csv).

На holdout ансамбль нашёл 113 из 160 ботов, ошибочно отметив 27 человеческих куки. Одиночный LightGBM на этом периоде лучше — 0.829630, но на двух периодах подбора хуже. Финальный ансамбль после этой проверки не заменялся.
